# Проверочный лист безопасности для бизнес-систем PropDevelopment

## Обоснование выбора разделов
На основе анализа архитектуры и проблем компании PropDevelopment были выбраны следующие разделы проверочного листа:
- **Управление доступом** - критически важно из-за множественных точек регистрации клиентов и проблем с контролем доступа к данным
- **Безопасность данных** - ключевой раздел из-за нарушенного контроля данных и планируемого расширения обработки данных
- **Защита инфраструктуры** - необходим для обеспечения безопасности сетевой инфраструктуры и интеграций с партнерами
- **Управление инцидентами** - важен для реагирования на инциденты типа утечки данных
- **Специфические аспекты** - включает вопросы удаленного доступа и физической безопасности, актуальные для распределенной инфраструктуры
